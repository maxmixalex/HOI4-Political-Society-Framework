## Vanilla symbol cache and external UI imports

Paths:

- `tools/ci/vendor/vanilla-symbols.cwv`
- `tools/ci/stock-ui-imports.json`

The symbol cache was generated by the pinned CWTools executable from the supplied vanilla script snapshot. It contains identifier indexes, paths, source positions and related lookup metadata. It does not contain the original script bodies, translated text, textures, audio or executable code. The original source material remains Paradox material; PSF's code license does not confer rights over it.

The UI import manifest records references already present in the supplied original GUI definitions. It supports validation when the archive omits game translations. Its temporary validation declarations are not shipped as game localization and do not replace the user's installed translations.

Hashes and provenance are recorded in [`tools/ci/toolchain.lock.json`](tools/ci/toolchain.lock.json). A complete local game installation can be supplied to validate against the user's own game data instead.
